# Soumission NASA Space Apps — mode d'emploi

Source : `docs/SOUMISSION PROJET_APPORTS DES MENTORS_CRITERES DE SELECTION PAR LES JURES.pdf`.

La page de projet, la démonstration et le lien public doivent être en **anglais**. Les textes à coller sont donc en anglais. Ce fichier reste en français.

La fenêtre de soumission se ferme le **dimanche 15 novembre 2026 à 23 h 59, heure locale**. Une soumission incomplète ou tardive n'est pas acceptée. On peut renvoyer le projet plusieurs fois : seule la dernière version est lue.

Le dépôt public est la branche `dev4`. C'est celle qui contient le jeu jouable du 15 novembre.

## Avant d'envoyer

- Tous les membres de l'équipe sont inscrits sur le site au moment de la soumission.
- Les cinq champs de texte et le lien sont remplis.
- Le jeu utilise des sorties GMAT et les éléments JPL : la condition « données NASA » des Global Awards est couverte. Le dire dans le champ NASA, pas seulement dans les références.
- Ne pas écrire qu'une mission réelle a été conçue avec DAS, le Trajectory Browser, PyCubed ou SPENVIS. Le jeu les cite. Les chiffres de trajectoire viennent de GMAT.
- Les 4 corrections par an de L1 restent une hypothèse. Le texte le dit déjà.

## Ce que les jurés notent

Impact, créativité, validité, pertinence pour le défi, présentation. Le pitch local a lieu le 15 novembre. Les nominés mondiaux passent ensuite devant les juges de novembre, puis devant le jury exécutif de décembre.
